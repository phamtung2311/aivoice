# Phase 40A — native Vietnamese synthetic speaker latent casting

This isolated private research experiment uses only the installed VieNeu 3.3.0
bundled preset embedding space and CPU/ONNX runtime. Four convex synthetic male
speaker embeddings share one fixed Northern storytelling reference-code anchor.

No user voice, Qwen, OpenVoice, Seed-VC, registration in production voice
storage, new model download, training, or production modification is involved.
