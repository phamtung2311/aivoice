# Reference checklist

Use only files for which the uploader has permission. These are manually uploaded research inputs, not AIVoice Voice Lab assets.

## Target speaker references

- Preferred: WAV, approximately 8–15 seconds.
- One person speaking clearly; neutral delivery is preferred.
- Low noise, no music, no overlapping people, little leading/trailing silence.
- The source accepts common audio formats and truncates at 15 seconds. The duration and WAV guidance are quality recommendations, not stricter hidden requirements.
- Use three acoustically distinct speakers: `speaker_A.wav`, `speaker_B.wav`, `speaker_C.wav`.

## Shared emotion donors

- Preferred: WAV, approximately 5–15 seconds.
- Record one clear happy, sad, and angry delivery: `emotion_happy.wav`, `emotion_sad.wav`, `emotion_angry.wav`.
- One donor may be reused across every target speaker. It is a global research control, not a custom emotional reference for each target speaker.
- Obtain the donor's permission. The donor must not be an unlicensed online clip, celebrity, or private recording.

## Do not upload

- AIVoice source code, databases, API keys, complete saved-voice library, or unrelated private audio.
- A target speaker's separate emotional recording for every requested emotion: that would defeat this experiment.
