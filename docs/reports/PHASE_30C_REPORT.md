# Phase 30C Report

2026-08-31 (Asia/Ho_Chi_Minh)

## Status

AUDITION_SET_GENERATED

## Objective

Generate a blind, user-auditionable set of up to ten genuinely distinct local
VieNeu speaker identities for Podcast Brand Voice R&D, without reference
scraping, synthetic voice variation, or production integration.

## Runtime Environment

The working AIVoice runtime is `/home/tung/ai voice/.venv/bin/python` (Python
3.14.7). `.venv/bin/uvicorn` is installed; system `/usr/bin/python` lacks the
project dependencies and system `uvicorn` is absent. The actual runtime has
VieNeu 3.3.0, NumPy 2.5.2, and pytest 9.1.1.

## VieNeu Speaker Capability Audit

The live local `V3TurboVieNeuTTS` ONNX instance exposes a `_preset_voices`
dictionary containing 20 packaged preset profiles. Each inspected profile has
its own `speaker_emb` and `codes`; metadata includes gender/style/description.
The installed package also exposes `add_voice` / `encode_reference`, which are
reference-cloning mechanisms, and the project restores separately saved local
profiles. No arbitrary new speakers are generated by sampling settings.

## Capability Classification

MULTIPLE_NATIVE_SPEAKERS_AVAILABLE. The installed runtime has more than ten
independent packaged local preset identities; no external reference was needed.

## Candidate Sources

Ten independently packaged preset profiles were used, prioritizing the nine
locally labelled male presets and one narration-friendly additional preset.
Saved user voices and Review Film were excluded to avoid altering or implicitly
promoting existing user/production profiles. Source identities are stored only
in the ignored blind mapping file.

## Candidate Count

10

## Audition Script

`phase30c_audition.txt` is an original four-sentence Vietnamese passage with
normal reflective prose and no engineered expressive tags. All candidates used
exactly this text, the existing local engine/chunking/WAV path, native sampling
defaults, and speed 1.0.

## Generated WAVs

Ten blind files were generated at
`experiments/special_voice_podcast/outputs/phase30c/`, named
`podcast_candidate_01.wav` through `podcast_candidate_10.wav`. Their measured
durations range from 22.40 to 35.28 seconds (mean 27.452 seconds), meeting the
intended approximately 20–35 second audition window.

## Blind Mapping

`phase30c_mapping.json` exists beside the outputs and uses deterministic
randomization seed 30003. It is ignored from Git and intentionally not disclosed
in this pre-listening report.

## Findings

VieNeu's packaged presets are legitimate independent speaker profiles, so the
project can audition ten local candidates without fabricating variations or
using external recordings. Preset metadata guided only pool construction; it
does not establish warmth, depth, comfort, or brand suitability.

## Limitations

This is a short audition only. It does not establish long-form comfort,
pronunciation stability, emotional suitability, or brand identity. The listener
must decide subjectively; source mapping remains hidden until that review.
